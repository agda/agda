Release notes for Agda version 2.8.0.2
======================================

This version fixes two issues with the released binaries.
No non-installation related issues were fixed over 2.8.0 or 2.8.0.1.
So if you have installed 2.8.0 or 2.8.0.1 already there is no need to upgrade to 2.8.0.2.

* Fix problem with missing `zlib1.dll` in released Windows binary ([issue #8733](https://github.com/agda/agda/issues/8733))
* Remove commit hash from version number in released binaries ([issue #8716](https://github.com/agda/agda/issues/8716))

* Agda supports GHC versions 8.8.4 to 9.14.1.
