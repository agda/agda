Ecosystem libraries
===================

This directory vendors large third-party Agda developments as git submodules.
We type-check them with the `agda` built from this repository in order to get
alerted of regressions we introduce on `master`.

| Submodule         | Upstream                                          |
|-------------------|---------------------------------------------------|
| `agda-categories` | <https://github.com/agda/agda-categories>         |
| `agda-unimath`    | <https://github.com/UniMath/agda-unimath>         |
| `plfa`            | <https://github.com/plfa/plfa.github.io>          |
| `TypeTopology`    | <https://github.com/martinescardo/TypeTopology>   |

(The standard library and the cubical library are vendored likewise, but at the
top level, as `std-lib` and `cubical`.)

Makefile goals
--------------

All goals live in the top-level `Makefile`; `LIB` below stands for the name of
one of the submodule directories above.

| Goal                     | Effect                                                     |
|--------------------------|------------------------------------------------------------|
| `make ecosystem`         | Check out all the libraries at their pinned revisions.      |
| `make LIB`               | Check out `LIB` at its pinned revision.                    |
| `make fast-forward-LIB`  | Move `LIB` to the tip of its default branch.               |
| `make ecosystem-test`    | Type-check all the libraries (takes hours).                |
| `make LIB-test`          | Type-check `LIB`.                                          |
| `make clean-ecosystem`   | Delete the `_build` directories with the interface files.   |

The tests pass `--no-default-libraries --library-file=ecosystem/libraries` to
Agda, where `ecosystem/libraries` (generated, `.gitignore`d) mentions only the
`std-lib` submodule.  So the libraries are checked against *our* standard
library, and the tests are independent of `~/.agda/libraries`.

Beware that Agda indexes the interface files under `LIB/_build` only by Agda
*version*, not by the git hash of the `agda` binary.  When re-testing with a
rebuilt `agda` of the same version, run `make clean-ecosystem` first (or pass
`AGDA_OPTS=--ignore-interfaces`), or you will be checking cached results.

Continuous integration
----------------------

The `ecosystem` job of `.github/workflows/test.yml` (generated from
`src/github/workflows/test.yml` by `make workflows`) runs one matrix entry per
library.  It runs on pushes to `master`, on the weekly schedule, on manual
dispatch, and on pull requests whose title contains `[ecosystem]`.

The submodules here are marked `update = none` in `.gitmodules`, so they are
*not* populated by `git clone --recurse-submodules` or by the recursive submodule
checkout that the CI jobs perform: they are big and only the `ecosystem` job
needs them.  This is why the Makefile checks them out with
`git submodule update --init --checkout`, which overrides `update = none`.

Notes on the individual libraries
---------------------------------

### agda-categories

`agda-categories.agda-lib` pins a released standard library
(`standard-library-2.4` at the time of writing) which does not type-check with
Agda `master`.  The `agda-categories` goal therefore applies
`patches/agda-categories-use-vendored-std-lib.patch`, which makes it depend on
the version-less library name `standard-library` so that our `std-lib`
submodule is picked up.  Consequently the working tree of this submodule is
always dirty; `.gitmodules` sets `ignore = dirty` for it.

The index module `Everything.agda` is generated by the library's own Makefile.

### agda-unimath

The index module `src/everything.lagda.md` is generated by the library's own
Makefile.

### plfa

PLFA is checked chapter by chapter by `plfa-test.sh`.  It cannot be checked in a
single Agda run (nor with `agda --build-library`): several chapters bind BUILTINs
(e.g. `BUILTIN NATURAL`) that the standard library binds as well, and each
BUILTIN can only be bound once per Agda run.

Only the book itself (`plfa/src/plfa`) is checked, not `plfa/courses` and
`plfa/extra`.

PLFA has a submodule `standard-library` of its own which we do not use and do
not check out.

### TypeTopology

The index module `source/AllModulesIndex.lagda` is maintained upstream.
